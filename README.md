# Dorothia

## 게임 설명

중세풍과 스팀펑크 세계관을 결합한 액션 방치형 게임입니다.
플레이어는 자동 전투와 성장 시스템을 기반으로 캐릭터를 강화하며, 다양한 장비와 스킬을 조합해 더 강력한 적에 도전하게 됩니다.

## 핵심 특징

⚙️ 스팀펑크 감성의 독특한 세계관

⚔️ 간편하지만 전략적인 액션 전투

💤 방치형 성장 시스템 (오프라인 보상 포함)

🎒 다양한 장비 및 강화 요소

## 설치 방법
안드로이드 기기에서 구글 플레이 스토어 실행

검색창에 도로시아 입력

다운로드 및 설치

실행 후 게임 시작

## 사용 기술 스택

#### 클라이언트 (Unity)
  - 엔진: Unity (6000.3.7f1)
  - 언어: C#

####  리소스 관리

  - Addressables (에셋 로딩 및 메모리 관리)
  - ScriptableObject (데이터 관리)

####  시스템 설계
- 디자인 패턴:
  - 싱글톤 (매니저 클래스)
  - 팩토리 패턴 (오브젝트 생성)
  - 옵저버 패턴 (이벤트 시스템)

- 데이터 처리
  - CSV / JSON 기반 데이터 테이블
  - 커스텀 데이터 파싱 시스템
